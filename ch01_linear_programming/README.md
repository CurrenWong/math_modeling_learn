## 2. Matlab → Python

```matlab
prob = optimproblem;                          % Python:
x = optimvar('x', 4, 4, 'LowerBound', 0);      %   变量数组 → numpy 向量（按行展平）
prob.Objective = 2800*sum(x(:,1)) + ...;       %   目标 → 一个 numpy 表达式
prob.Constraints.con = [sum(x(1,:)) >= 15, ...]; %  约束 → A_ub / A_eq 矩阵
[sol, fval, flag, out] = solve(prob);         %   res = scipy.optimize.linprog(...)
```

**三条最容易被坑的地方：**

1. **`linprog` 只做最小化。** 书里几乎全是「最小化费用 / 最大化收益」。
   本工程用 `solve_lp(..., maximize=True)` 统一处理（内部取负，返回值已还原）。

2. **`linprog` 的不等式只接受 `≤`。** 模型的 `≥` 约束要整体乘 -1：
   `A_ub = [-row]`, `b_ub = [-need]`。**这个符号错误最常见，而且报错信息很难懂**
   （本工程调试时就踩过：约束写反 → 求解器直接说 infeasible）。

3. **解可能是多重的。** 例 1.4 里书给的解和 HiGHS 给的解不同，但目标值一样。
   所以**检验模型要看目标值和可行性，不要逐元素比对解向量**。

## 3. 四个例题逐个讲

### 例 1.4 仓库租赁（`ex1_4_warehouse.py`）

**模型**：设 x_ij = 第 i 个月初签的、租期 j 个月的仓库面积。

关键在于「在租面积」怎么算：第 i 个月的在租面积 = 当月新签的 + 之前签的**尚未到期**部分。
所以第 3 个月的在租面积是 `x13 + x14 + x22 + x23 + x31 + x32`——注意 x21 只有 1 个月，
第 3 个月时已经过期了。

代码里用循环自动生成约束矩阵（`i <= k <= i+j-1` 判断合同在第 k 月是否仍生效），
比手写 4 条约束更不容易错，也更容易推广。

**书中答案**：z = 118400，x11=3, x31=8, x14=12。
**代码结果**：z = 118400 ✅，但解是 x11=5, x14=10, x31=8, x32=2——**另一个最优解**。
脚本里专门把书中的方案拿回来独立验证（同样可行、同样 118400），
这正是多重最优解的教科书式例子。

### 例 1.6–1.8 线性化（`ex1_7_abs_linearization.py`）

**这是第 1 章最有价值的一节。** 三个技巧：

1. **绝对值**：`x_i = u_i - v_i`（u,v ≥ 0），则 `|x_i| = u_i + v_i`。
   于是 `min Σ|x_i|` 变成 `min Σ(u_i+v_i)`，变量数翻倍但完全线性。

   ```python
   # 变量顺序 [u1..u4, v1..v4]
   c_full = np.concatenate([c, c])
   A_ub = np.hstack([A, -A])        # A(u-v) <= b
   ```

2. **max 绝对值**：`min max_i |eps_i|` → 引入 v，写成 `-v <= eps_i <= v`。
   例 1.8 里代码**只对 v 这一个变量求解**（eps_i 是已给定的量）——
   如果把 x 也放开变量，求解器会让 x = y 使 v = 0，这是建模错误，不是求解错误。

3. **注意不等号方向**：`eps_i <= v` 写成 `A v <= b` 时是 `-v <= -eps_i`，
   不是 `+v <= -eps_i`。方向写反模型就不可行。

### 例 1.9 投资收益与风险（`ex1_9_portfolio.py`）

1998 年全国数学建模竞赛 A 题，本章最综合的例子。

**三个模型：**

- **模型一**（固定风险水平 a，最大化收益）：a 从 0 扫到 0.05，步长 0.001，
  每个 a 解一个 LP，画出风险—收益曲线。书上结论：a ≈ 0.006 处有转折。
  代码在 a=0.006 得到 Q = 2019.08、投资分配 (0, 2400, 4000, 1090.91, 2212.21)，
  与书的 (0, 2400, 4000, 1091, 2212) 一致。

- **模型二**（固定盈利水平 k，最小化风险）：书上留作习题，思路与模型一对称。

- **模型三**（加权求和）：`min w·风险 - (1-w)·收益`。
  **关键是把 `max_i q_i x_i` 线性化**：引入 x_{n+1}，约束 `q_i x_i <= x_{n+1}`。
  代码逐个 w 输出风险/收益表，**与书中表 1.5、1.6 的每一个数字都对上**：

  | w | 0.0–0.7 | 0.8 | 0.9 | 1.0 |
  |---|---|---|---|---|
  | 风险 | 247.52 | 92.25 | 59.40 | 0 |
  | 收益 | 2673.27 | 2164.82 | 2016.24 | 500 |

  w = 1.0 时全部存银行（收益 500、风险 0），这是模型必然的结果，不是 bug。

**图**：`figures/ch1_portfolio.png` 左边是模型一的风险—收益曲线（标出转折点），
右边是模型三画出的有效前沿。

## 4. 易错清单

- [ ] `≥` 约束记得乘 -1 变成 `≤`
- [ ] 最大化记得取负（或者用 `maximize=True`）
- [ ] 变量展平顺序要和 `A` 矩阵的列顺序一致（代码里统一用 `idx(i,j)` 函数）
- [ ] 不要用 `==` 写等式约束的浮点比较
- [ ] 最优解不唯一时，比对目标值
- [ ] 建模完成后**把书上的答案代回去验一遍**，这是最快的自检

## 5. 自测题

1. 为什么 `linprog` 里把 `x ≥ 0` 写成 `bounds=(0, None)`，而不是写成约束行？
   （答：变量非负性由求解器直接处理更快；写成约束也可以但要多占 m 行）
2. 例 1.7 中如果把 `u, v ≥ 0` 的约束漏掉，模型会变成什么样？
   （答：`|x_i| = u_i + v_i` 不再成立，u+v 可以被压到 0，目标值变成 0，错得很隐蔽）
3. 例 1.9 模型一里，a 从 0 增加到 0.05 时收益一直在涨吗？
   （答：涨到 a≈0.03 之后饱和在 2673.27——全部资金买 S1，风险已经用尽）
4. 例 1.9 中如果把「风险最大用尽」的资产先后顺序搞反（先买 S3 而不是 S2），
   曲线会怎么变？（答：S3 的收益/风险比最低，曲线前段会明显变平）
5. 为什么模型三在 w ≤ 0.7 时风险收益都不变？
   （答：此时目标函数几乎只由收益主导，解始终是「全买 S1」这一个顶点）
