## 2. Matlab → Python

```matlab
x = optimvar('x', 6, 'Type','integer','LowerBound',0);   % Python:
prob.Constraints.con = [sum(x,1)==1; sum(x,2)<=2];        %   scipy.optimize.milp(
[sol,fval,flag] = solve(prob);                            %     c=..., integrality=..., bounds=...)
```

`scipy.optimize.milp` 的关键参数：

```python
res = optimize.milp(
    c=c,                                   # 目标系数（最小化）
    constraints=[optimize.LinearConstraint(A_ub, lb, ub)],  # lb=-inf, ub=... 即 ≤
    integrality=np.array([...]),           # 1=整数, 0=连续（可以混合！）
    bounds=optimize.Bounds(lo, hi),
)
```

**混合整数**是 `milp` 相对 `linprog` 的最大优势：
部分变量整数、部分连续（比如「建几个厂」是整数，「厂址坐标」是连续），
这在选址类问题里很常见。

## 3. 六个例题逐个讲

### 例 2.5 工人排班（`ex2_5_scheduling.py`）

**模型**：`min Σx_i`，约束 `x_i + x_{i-1} >= need_i`（每人连续工作 8h = 跨两个班次，
跨午夜时 6 号班接 1 号班）。

**两个坑：**

1. **约束方向**：linprog 只吃 `≤`，所以要写成 `-x_i - x_{i-1} <= -need_i`。
   本工程调试时正是在这里符号写反，模型直接 infeasible。
2. **覆盖关系的方向**：第 k 个班次的人来自「本班次 + 上一班次」，
   不是「本班次 + 下一班次」。写反了答案看起来也很合理，但会得到另一个解。

结果：140 人，x = (35, 5, 45, 0, 55, 0)，与书一致 ✅。
脚本还算了 LP 松弛解做对比——**本例松弛解恰好也是整数**，但一般情况下会是 34.7 个人，
这时整数规划就是必需的。

### 例 2.6 装修分配（`ex2_6_assignment.py`）

4 家公司、5 个门店，人数与任务数不等，**不是标准指派问题**，
所以不能套 Hungarian，要用 0-1 规划：每店恰好一家（`Σ_i x_ij = 1`），
每家最多两店（`Σ_j x_ij <= 2`）。

结果 63.8 万元，分配方案 A→3、B→4、C→1,2、D→5，**与书完全一致** ✅。

### 例 2.7 供应站选址（`ex2_7_facility.py`）

这是「固定成本 + 覆盖」的经典模型，四个约束层次：

```
min Σ x_i
s.t. Σ_i y_ij >= 1        每个网点被覆盖
     d_ij·y_ij <= 10·x_i  只能覆盖 10km 内
     Σ_j y_ij <= 5        每站最多服务 5 个
     x_i >= y_ij,  x_i = y_ii
```

**注意**：`d_ij·y_ij <= 10·x_i` 是线性的（d 是常数），不用大 M。

结果：**2 个站** ✅，但位置是网点 2、8（书上是 5、8）——**另一个最优解**。
脚本做了独立复核：按模型给出的 y 检查覆盖数 ≤ 5、距离 ≤ 10km、并集覆盖全部 10 个网点；
同时把书上的方案也验证了一遍（同样可行）。

### 例 2.8 蒙特卡洛求面积（`ex2_8_monte_carlo.py`）

曲边三角形 y=x²、y=12-x 与 x 轴围成的面积。

**精确值 49.5**（∫₀³x²dx + ∫₃¹²(12-x)dx = 9 + 31.5），用来检验模拟精度。

Matlab 时代用 10⁷ 次单点循环，Python 里用 numpy 向量化 + 分块，**1 秒不到**。

脚本展示了蒙特卡洛最重要的性质：

| N | 10⁴ | 10⁵ | 10⁶ | 10⁷ |
|---|---|---|---|---|
| 绝对误差 | 0.19 | 0.02 | 0.05 | 0.02 |

**误差 ~ 1/√N**：样本量翻 100 倍，误差只缩小 10 倍。这是「便宜但慢收敛」的本质。

### 例 2.9 非线性整数规划（`ex2_9_nlp_integer.py`）

枚举要算 100⁵ = 10¹⁰ 个点。书用蒙特卡洛（10⁶ 点）得到 z = 50273，
Lingo 精确最优是 z = 51568。

**本工程做了两件事：**

1. 复现蒙特卡洛（向量化采样 + 逐点可行性判定，比书里的 Matlab 循环快几个数量级）；
2. **在 MC 解上做整数邻域爬山**，精确爬到 x = (50, 99, 0, 99, 20), z = 51568 ✅——
   和 Lingo 的答案完全一致。

**爬山邻域设计是这个例子的精髓**：只做「单变量 ±1」会卡在局部最优——
约束 `2x1 + x2 + 6x3 <= 200` 把三个变量耦合，从 [49,96,1,...] 到 [50,99,0,...]
必须**同时动两个变量**。加上 (+1,-1) 这类两变量联动移动后，一次就爬到全局最优。

脚本还做了 10 次随机重启：9/10 次到达 51568，1 次停在 49972——
说明「MC 给初值 + 局部搜索」也不是 100% 可靠，**多次重启更稳**。

### 例 2.10 比赛项目排序（`ex2_10_tournament_tsp.py`）

2005 年电工杯 B 题，思路很漂亮：

1. **把比赛项目当图的顶点**，边权 = 同时参加这两个项目的人数 `w_ij = Σ_m a_mi a_mj`；
2. 目标变成「找顶点排列使相邻边权和最小」= **旅行商问题**；
3. 起点终点之间没有连接 → 引入虚拟项目 15，边权全 0，把问题变成 15 点 TSP，
   求最短回路后去掉虚拟点。

**MTZ 割（消除子回路）**：

```
u_i - u_j + n·x_ij <= n-1     (i, j 均非锚点)
1 <= u_i <= n-1
```

**本工程调试这个模型时踩了三个坑，都写进注释了：**

- **锚点选错**：必须让虚拟点 15 当锚点（u_15 = 0），回路才能从它出发；
- **u 的上下界符号写反**：`-u_i <= -(n-1)` 实际含义是 `u_i >= n-1`，
  写成这样模型直接 infeasible。正确写法：`-u_i <= -1`（下界）和 `u_i <= n-1`（上界）。
- **自环变量**：x_ii 用大数（1e7）罚会让 HiGHS 数值不稳，
  改成用等式约束 `x_ii = 0` 显式禁掉。

结果：**回路总长 2** ✅（与书一致），顺序是 10→13→4→9→14→12→2→6→3→11→7→5→1→8，
与书的顺序不同但同样最优。脚本用报名表**独立重算**了连续参赛人次，确认是 2。

## 4. 易错清单

- [ ] `≥` 约束 → 乘 -1 变 `≤`
- [ ] 等式约束别忘了减右端项（`r @ x - c`）
- [ ] `milp` 的 `bounds` 可以给标量 `(0,1)`，也可以逐变量给
- [ ] `integrality` 数组长度 = 变量数，1 是整数 0 是连续
- [ ] TSP 的 MTZ 割要选对锚点，且 u 的上下界别写反
- [ ] **多重最优解**：比对目标值和可行性，不要死抠解向量

## 5. 自测题

1. 例 2.5 里如果允许「第 k 班次的人来自本班次 + 下一班次」，答案会变成什么？
   （答：仍是 140，但分配会平移到另一种写法；这个模型本身有旋转对称性）
2. 为什么例 2.6 不能直接用 Hungarian 算法？
   （答：4 人 5 任务，人数不等，且每家最多 2 店是额外约束，不是标准指派）
3. 蒙特卡洛求面积，N 增大 100 倍，标准差缩小几倍？（答：10 倍，因为误差 ~ 1/√N）
4. 例 2.9 中如果爬山邻域只允许单变量 ±1，会卡在什么解？
   （答：[49,96,1,99,20] 附近，z ≈ 50898，比最优 51568 差 670）
5. 例 2.10 里为什么必须引入虚拟点 15？
   （答：首尾两项之间没有先后关系，直接做 TSP 会强行让首尾相连；虚拟点权重为 0，
   去掉它就还原成「路径」而非「回路」）
