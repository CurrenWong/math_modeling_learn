## 2. Matlab → Python

```matlab
prob = optimproblem;                       % Python:
x = optimvar('x', 2, 'LowerBound', 0);     %   scipy.optimize.minimize(
prob.Objective = sum(x.^2) - 4*x(1) + 4;   %     f, x0, method='SLSQP',
prob.Constraints.con = [g1 <= 0; g2 <= 0]; %     bounds=..., constraints=[...])
x0.x = rand(2,1);                          %   x0 必须给（局部方法）
[sol, fval, flag, out] = solve(prob, x0);
```

**scipy 的约束写法**（与 Matlab 相反）：

```python
constraints = [
    {"type": "eq",   "fun": lambda x: r @ x - c, "jac": lambda x: r},
    {"type": "ineq", "fun": lambda x: g(x)},     # 要求 g(x) >= 0！
]
```

Matlab 的 `g(x) <= 0` 要写成 scipy 的 `-g(x) >= 0`，**符号必须翻**。

**给解析 Jacobian 会让 SLSQP 稳很多**，本工程里所有脚本都提供了。

## 3. 六个例题逐个讲

### 例 3.1 凸 NLP（`ex3_1_convex_nlp.py`）

```math
\min f = x_1^2 + x_2^2 - 4x_1 + 4
\text{s.t. } -x_1+x_2-2 \le 0,\quad x_1^2-x_2+1 \le 0,\quad x\ge 0
```

脚本做三件事：

1. **判凸性**：Hessian 特征值全为正 → f 严格凸；g2 的 Hessian 半正定 → g2 凸；
   g1 线性 → 整个问题是凸规划，**K-T 条件是充分条件**。
2. **求解**：x* = (0.5536, 1.3064), f* = 3.7989 ✅ 与书一致。
3. **验证 K-T 条件**：找出起作用的约束（只有 g2），解出乘子 λ = 2.6129 ≥ 0，
   平稳性残差 1.4e-9，互补松弛 λ·g(x*) = 1.7e-10。

脚本还做了**初值敏感性测试**：4 个差别很大的初值都收敛到同一个解——这正是凸问题的特征。

### 例 3.2 彩电定价（`ex3_2_tv_pricing.py`）

书里强调的**建模五步法**，本脚本完整走了一遍：

1. 提出问题（变量表 + 假设表）→ 2. 选方法（无约束最优化）→
3. 推导（把售价、成本、收入写成 x 的函数）→ 4. 求解 → 5. 回答问题 + 灵敏度分析。

推导结果：

```math
f = -0.01x_1^2 - 0.007x_1x_2 - 0.01x_2^2 + 144x_1 + 174x_2 - 400000
```

凹二次函数，令 ∇f = 0 即可解析求解：x1 = 4735.04, x2 = 7042.74。
数值求解给 x = (4733.34, 7043.45), f = 553641.00 ✅（书上 553641.025）。

**灵敏度分析**（第 5 步的关键）：对 19 英寸的价格弹性 a 做扫描，

| a | 0.006 | 0.010 | 0.015 | 0.020 |
|---|---|---|---|---|
| 最优 x1 | 8703 | 4733 | 3016 | 2213 |
| 年利润 | 718450 | 553641 | 482229 | 448852 |
| 利润率 | 21.3% | 19.0% | 17.8% | 17.2% |

a 越大（卖得越多降价越狠）→ 产量越小、利润越薄。
**这就是「薄利多销 vs 厚利少销」在模型里的样子。**

图：`figures/ch3_tv_pricing.png`（三维曲面 + 水平集，对应书里的图 3.1/3.2）。

### 例 3.3 / 3.4 二次规划（`ex3_3_quadratic.py`）

```math
\max -x_1^2 - 0.3x_1x_2 - 2x_2^2 + 98x_1 + 277x_2
\text{s.t. } x_1+x_2\le 100,\ x_1-2x_2\le 0,\ x\ge 0
```

H = [[-1,-0.15],[-0.15,-2]] 负定 → 凹函数 → **最大化是凸问题** → 解唯一。
结果 x = (35.3704, 64.6296), f = 11077.8704 ✅ 与书一致（4 个初值全部相同）。

**例 3.4 是同一函数的最小化版本 → 非凸**。书中 Matlab 只找到局部解 (1,1), f=371.7，
并指出 (0,0) 可行且 f=0 更好。本脚本用 8 次随机重启，每次都找到了 f = 0 的解 ✅。

脚本还给了**不依赖求解器的交叉验证**：固定 x2 时目标关于 x1 是凹二次，驻点
`x1* = (98 - 0.3x2)/2`，再按两个约束截断，网格扫描得到与 SLSQP 一致的解。

> 调试提示：截断这一步不能省——最优解处起作用的是 `x1+x2 ≤ 100` 而不是驻点，
> 只算驻点会得到 (40, 60) 这种次优解。

### 例 3.8 Markowitz 组合（`ex3_8_markowitz.py`）

脚本先用**表 3.2 的原始数据反算**均值和协方差，核对出书里的表 3.3 用的是
**样本协方差（分母 n-1）**（ddof=0 会对不上）——这个口径细节很值钱。

- 问题 (1)：`min x'Fx s.t. Σx=1, μ'x ≥ 0.15, x ≥ 0` → x = (0.5269, 0.3578, 0.1154)，方差 0.0228 ✅
- 问题 (2)：`max μ'x s.t. Σx=1, x'Fx ≤ 0.09, x ≥ 0` → x = (0, 0.0562, 0.9438)，收益 0.2334 ✅

两个问题都是凸规划。脚本还扫出有效前沿并出图 `figures/ch3_markowitz.png`。

**一个有意思的结论**：问题 (2) 里 A 的权重是 0——A 方差小但收益也低，
在 0.09 的风险额度下不如全押 C。**这就是分散化的代价。**

### 例 3.9 两料场选址（`ex3_9_supply_location.py`）

```math
\min \sum_{i,j} z_{ij}\sqrt{(x_j-a_i)^2+(y_j-b_i)^2}
\text{s.t. } \sum_j z_{ij} = c_i,\quad \sum_i z_{ij} \le 20,\quad z\ge 0
```

**书里 MATLAB 的 `sum(z)<=20` 是笔误**——总需求 36，那样必然不可行；
正确写法是按料场分别约束（脚本用的是正确版本）。

本脚本 12 个随机初值全部收敛到同一个解：

| | 料场 1 | 料场 2 | 总吨千米 |
|---|---|---|---|
| 书 | (7.25, 7.75) | (3.2942, 5.1790) | 72.6303（**局部最优**） |
| 代码 | (7.25, 7.75) | (3.2653, 5.1920) | **71.9352** |

我们的解**比书的更好**，而且与书中「每工地由一个料场供应」的调整方案 71.9372 几乎相同。
书中那个 72.6303 的解里，多个工地被两个料场分供（工地1：料场1 给 0.0329、料场2 给 2.9671），
是随机初值下的局部最优。

**调整方案的一个额外坑**：单纯「就近分配」会超容量（可能让一个料场供 25t > 20t），
所以脚本改成**枚举 2⁶ = 64 种分配**，在满足容量的方案里挑吨千米最小的。

### 例 3.10 飞行管理（`ex3_10_flight.py`）

1995 年全国数学建模竞赛 A 题，本章最难、也最有价值的例子。

**几何判据**：把飞机 i 看作不动，j 以相对速度运动，危险角
`α_ij = arcsin(8/r_ij)`，调整后相对角 `β + (Δθ_i+Δθ_j)/2`，
不碰撞条件 `α < β < 2π-α`（书的平方形式 `|β+s|² ≥ α²` 与之等价）。

脚本复现了**表 3.8（α）和表 3.9（β）**，抽样全部一致 ✅。

**然后本工程做了一个书中没做的检查：把书给出的答案代回它自己的约束里。**

书给 Δθ5 = 2.7979°、Δθ6 = 0.9330°（总调整 3.7310°）。逐对检查 15 个机对，
**机对 (3, 新进入) 不满足约束**：`|β+s| = 0.777° < α = 2.125°`。

**仿真给出硬证据：**

| 方案 | 最小机间距 | 判定 |
|---|---|---|
| 不做任何调整 | 1.175 km | ★ 危险 |
| **书中的调整角** | **2.927 km** | **★ 依然危险** |
| 本工程的解（Δθ3=2.558°, Δθ6=1.072°） | 8.000 km | 安全 |

**模型二**（对所有时刻成立、目标为平方和）用等价的「两轨迹垂距」表述实现，
数值量级好得多（~10⁴ vs ~10¹⁰），从模型一的解热启动后收敛：
Δθ3 = 2.0624°, Δθ4 = -0.4954°, Δθ6 = 1.567°，仿真最小间距 8.0006 km ✅。

**调试这个脚本时踩的坑（都写在注释里）：**

1. 约束符号写反：`|s| ≥ α` 等价于 `(s/α)² - 1 ≥ 0`，我写成了 `1 - (s/α)² ≥ 0`，
   导致所有约束在起点就是负的，求解器直接放弃。
2. 解析梯度漏了 `∂s/∂v = 1/2` 这个因子，梯度大了一倍，方向全错。
3. **单位重复换算**：变量本身就是「度」，又套了一次 `np.degrees`，
   一度变成 57.3 度，输出离谱。

## 4. 易错清单

- [ ] scipy 约束要求 `>= 0`，Matlab 的 `<= 0` 要翻符号
- [ ] **非线性规划必须给初值**，且初值会影响结果
- [ ] 凸问题可以相信单个解；非凸问题必须多起点
- [ ] 有解析 Jacobian 就给上，SLSQP 会稳很多
- [ ] **模型解 ≠ 实际可行**：一定要独立验证（仿真、代回约束、检查量纲）
- [ ] 弧度/度、米/千米、角度/弧度这类单位错误最难查，写代码时统一在一个单位下

## 5. 自测题

1. 例 3.1 里如果去掉 `x ≥ 0` 的约束，最优解会变吗？
   （答：不变，因为最优点 x* = (0.5536, 1.3064) 本来就在第一象限；但其他问题里去掉会变）
2. 例 3.3 中 H 的特征值为负，为什么「最大化」反而是凸问题？
   （答：凹函数求最大 = 凸函数求最小，H 负定即 x'Hx 凹；同样的函数改成最小化就非凸）
3. 例 3.2 中如果售价不再随销量下降（a = 0），模型会怎样？
   （答：目标变成线性+二次无交叉项，问题仍然良定义，但「以价换量」的权衡消失，
   最优产量会显著变大）
4. 例 3.8 里协方差矩阵如果用总体口径（ddof=0）会怎样？
   （答：所有方差和协方差缩小 11/12 倍，组合方差也缩小，最优比例不变但风险数值对不上书）
5. 例 3.10 里为什么书的方案在仿真里也过不去？
   （答：它违反了 (3, 新进入) 这一对的约束，而这正是最危险的一对——
   新进入飞机几乎正对着 3 号机飞，相位差只有 0.31°，危险角却是 2.13°）
